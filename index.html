Flash P4 Digital Mixing

8 mix channels · 15-band EQ · WebSocket console · 48 kHz

This browser can't flash boards. Use Chrome or Edge on a desktop. Open this page over HTTPS to install firmware. Wiring guide

Connect the P4 board with a USB data cable before clicking Install. Check the wiring guide for PCM1808/PCM5102 pinout.

What happens

  1. Click Install firmware.
  2. Pick the board's serial port and confirm.
  3. Flash is erased, then the firmware is written.
  4. The board reboots when it says Installation complete.

Heads-up
