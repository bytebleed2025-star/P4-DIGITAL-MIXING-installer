Use one common ground. Do not feed 5 V into any P4 GPIO. Keep I2S wires short and add 100 nF + 10 uF at each codec board.

Optional PCM5102 output

Output is disabled by default. Choose a free P4 header GPIO, set it in main/settings.h:

#define I2S_DOUT_PIN <free GPIO>

The PCM5102 output is line level (~2 Vrms). Never connect it directly to a speaker. Use a power amplifier or active speakers.

Board notes

  • The P4-NANO uses its on-board ESP32-C6 for Wi-Fi over SDIO; those pins are internal and not part of this wiring.
  • I2S0 is reserved for the on-board ES8311. The mixer uses I2S_NUM_1 on the header pins above.
  • Check the P4-NANO header silkscreen: use the GPIO number, not the physical pin number.
  • If clocks ring or the codec locks unreliably, add a 33-100 ohm series resistor at the P4 end of MCLK/BCK/LRCK.
